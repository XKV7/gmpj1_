# 바람의 배달부 (Windcourier)

구름 위에 떠 있는 섬들 사이를 글라이더로 날며 편지와 화물을 배달하는 3D 오픈월드 비행 어드벤처입니다.
지형, 소품, 텍스처, 사운드, 음악까지 **모든 것이 코드로 절차 생성**됩니다. 외부 에셋 파일은 하나도 없습니다.

- Vite + TypeScript(strict) + Three.js. 런타임 의존성은 three 하나뿐입니다.
- 수채화풍 툰 셰이딩, 화면 공간 외곽선, 고도에 따라 색이 바뀌는 높이 안개, 대기 산란 하늘
- 실제 글라이더 비행 모델(양력, 항력, 받음각, 실속, 에너지 교환)
- 상승기류, 바람 강, 폭풍 지대
- 퀘스트 23개, 업그레이드, 꾸미기, 바람 조각 30개, 링 레이스 3코스, 엔딩

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 체크(`tsc --noEmit`) 후 프로덕션 빌드(`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run typecheck` | 타입 체크만 |
| `npm test` | Vitest 단위 테스트(비행 물리, 퀘스트 로직, 월드 생성) |

WebGL2를 지원하는 최신 브라우저(Chrome, Edge, Firefox, Safari 16 이상)가 필요합니다.
소리는 처음 클릭하거나 키를 누를 때 켜집니다(브라우저 자동재생 정책).

### 헤드리스 검증 스크립트 (선택)

`scripts/`에는 Playwright로 실제 게임을 띄워 검증하는 스크립트가 있습니다. Playwright는 의존성에 포함하지 않았으므로 따로 설치해야 합니다(`npm i -D playwright && npx playwright install chromium`).

```bash
npm run build && npx vite preview --port 4173 &
node scripts/smoke.mjs       http://localhost:4173/ screenshots   # 타이틀 → 시작 → 걷기 → 이륙 → 비행 → 지도 → 시간대, 콘솔 에러 0 확인
node scripts/playthrough.mjs http://localhost:4173/ screenshots   # 23개 퀘스트 전부 배달 → 엔딩 → 계속 날기
node scripts/showcase.mjs    http://localhost:4173/ screenshots   # 바람 강·상승기류·폭풍·구름·노을 등 풍경 스크린샷
```

소프트웨어 WebGL은 매우 느리므로, 스크립트는 게임의 `debugAdvance()` 훅으로 시뮬레이션을 앞당깁니다.

## 조작법

**비행: 쉬운 조작(기본)**

키보드만으로 조종합니다. 키를 놓으면 지금 방향 그대로 완만하게 활공합니다. 쉬운 조작에서는 바람이 속도를 받쳐 주어서 S를 누르면 초당 약 9m씩 실제로 올라갑니다.

| 입력 | 동작 |
| --- | --- |
| `W` / `↑` | 하강 |
| `S` / `↓` | 상승 |
| `A` `D` / `←` `→` | 왼쪽 / 오른쪽으로 돌기 |
| `Shift` | 날개 접기: 급강하해서 속도를 얻습니다 |
| `Space` | 날개 활짝: 감속(착륙 준비) |
| `V` | 1인칭 / 3인칭 |
| `R` | 레이스 포기 |

**비행: 고급 조작(설정 → 비행 조작)**

기체를 직접 조종합니다. 마우스와 `W` `S`는 피치(W 기수 내림)입니다. 마우스와 `A` `D`는 롤이고, 기울이면 선회하며 놓으면 수평으로 돌아옵니다. `Q` `E`는 요입니다.

**지상**: `WASD` 걷기, `Shift` 달리기, `Space` 점프, `F` 이륙, `E` 대화·배달·우체국, 마우스 휠로 카메라 거리 조절.
절벽에서 뛰어내리면 글라이더가 저절로 펼쳐집니다.

**공통**: `M` 지도, `J`/`Tab` 퀘스트 로그·기록, `P` 사진 모드, `Esc` 일시정지, `F3` 디버그 오버레이(FPS, 드로우콜, 삼각형 수, 위치, 시드).

**게임패드(표준 매핑)**: 왼스틱 방향(고급 조작에서는 피치/롤), 오른스틱 시점, LB/RB 요, RT 급강하, LT 감속, A 점프/이륙, X 상호작용, Y 시점 전환, Back 지도, Start 일시정지.

## 플레이 안내

1. 바람마루 우체국의 게시판(또는 우체국장 도담)에서 의뢰를 받습니다.
2. 의뢰 종류에 따라 비행 방식이 달라집니다.

   | 종류 | 특징 |
   | --- | --- |
   | 일반 편지 | 제한 없음. 받는 사람 섬의 우편함에 넣어도 됩니다 |
   | 급송 | 시간 제한, 금색 링 경로를 모두 통과해야 합니다. 링을 지나면 작은 돌풍을 받습니다 |
   | 깨지기 쉬움 | 거친 착지, 높은 G, 난기류, 번개에 손상됩니다. 상태에 따라 보상이 줄어듭니다 |
   | 무거운 화물 | 질량이 늘어 더 빨리 가라앉습니다. 상승기류를 타야 합니다 |
   | 야간 배달 | 밤에만 만날 수 있습니다. 등대 불빛이 달꽃섬 쪽을 가리킵니다. 우체국에서 밤까지 쉴 수 있습니다 |

3. 받는 사람에게 다가가 `E`를 누르면 배달 완료입니다. 감사 대사와 함께 깃털을 받습니다.
4. 깃털로 업그레이드(양력, 최대 속도, 실속 저항, 화물 칸)와 날개 색 10종, 무늬 10종을 구매합니다.
   바람 조각 10개를 모으면 「별자리」, 30개를 모으면 특별한 「바람 날개」 무늬가 해금됩니다.
5. 22개의 배달을 마치면 마지막 편지가 열립니다. 폭풍의 눈 한가운데 있는 하늘등대로 가면 엔딩입니다.

**비행 요령**
- 떠오르는 꽃잎과 아지랑이가 보이는 기둥이 상승기류입니다. 원을 그리며 오르세요.
- 반짝이는 줄기는 바람 강입니다. 들어가면 기류에 실려 빠르게 날아갑니다.
- 너무 느리면 실속 경고음이 울리고 기수가 떨어집니다. 기수를 내려 속도를 회복하세요.
- 너무 빠르게 부딪히면 잠시 기절했다가 가장 가까운 섬에서 다시 시작합니다. 깃털은 잃지 않습니다.

### 씬 구조

하늘 돔(카메라 추적, 깊이 미기록) → 구름바다 층(맨 아래는 불투명) → 섬 LOD + 섬별 near/far 소품 그룹 → 다리, 부유 파편 → 바람 시각화 → 플레이어, 주민, 새, NPC → 링, 수집품 → 볼륨 구름(투명, 뒤에서 앞으로 정렬) → 이펙트

### 프레임 업데이트 순서

1. 입력 폴링, 전역 단축키
2. 환경(시간, 해/달, 조명, 안개/구름 색)
3. 바람장 샘플링(플레이어 위치)
4. 플레이어: 비행 물리(1/120초 서브스텝), 착륙 보조, 충돌(섬 윗면/측면/아랫면, 건물, 다리), 걷기
5. 게임 로직: 링 판정, 퀘스트 타이머와 화물 손상, 수집품, 섬 발견, 기록, 번개, 자동 저장
6. 주민, 새 떼, NPC 글라이더, 풍차, 등대, 다리
7. 카메라
8. 이펙트(비행운, 속도선, 파티클), 오디오, HUD
9. 렌더: 그림자 → HDR 씬 → 블룸 → 합성

### 비행 모델

몸체 축은 전방 −Z, 위 +Y, 오른쪽 +X입니다. 기체가 받는 힘(단위 질량당)은 다음과 같습니다.

- 양력 `kL·A·CL(α)·v²`: 기류에 수직이고 날개 평면 안에 있습니다. CL은 받음각에 선형으로 늘다가 실속각을 넘으면 급감합니다.
- 항력 `kL·A·(CD0 + K·CL²)·v² + k_body·v²`: 유도 항력과 형상 항력의 합입니다.
- 중력, 그리고 옆미끄럼을 줄이는 측력.

날개를 접으면(`Shift`) 날개 면적이 줄어듭니다. 날개를 펴면(`Space`) 면적, 최대 양력 계수, 항력이 늘어납니다.

회전은 입력 각속도에 안정성 항(받음각과 옆미끄럼을 기류 쪽으로 되돌리는 항)을 더해 계산합니다. 그래서 피치를 당기고 있으면 받음각이 유지됩니다. 실속하면 기수가 떨어지고 기체가 떨립니다.

업그레이드는 양력 계수, 형상 항력, 실속각을 바꿉니다. 무거운 화물은 질량 계수를 높입니다.

바람 강의 기류가 바뀌면 그 변화만큼 지상 속도에 더해서 대기속도를 유지합니다. 그래서 강에 들어가면 실속하지 않고 실려 가고, 나올 때는 가속 일부를 유지합니다.

### 성능

- 섬 메시는 시작할 때 한 번 생성합니다. 로딩 화면이 진행률을 보여 줍니다.
- 소품은 섬마다 종류별 `InstancedMesh` 1개입니다. 경계 구로 프러스텀 컬링하고, 거리에 따라 near/far 그룹을 숨깁니다.
- 섬은 `THREE.LOD`(고/저 메시)를 쓰고, 그림자는 플레이어 주변 220m만 텍셀 스냅으로 그립니다.
- 품질 설정은 다음과 같이 다릅니다.

  | 품질 | 렌더 해상도 | 그림자 | 블룸 | 방사형 블러 | 풀 밀도 | 구름 양 | 소품 거리 |
  | --- | --- | --- | --- | --- | --- | --- | --- |
  | 낮음 | 0.85배 | 없음 | 없음 | 없음 | 35% | 45% | 짧게 |
  | 중간 | 1배 | 1024 | 있음 | 5샘플 | 65% | 75% | 중간 |

### 저장

설정과 진행 상황은 `localStorage`에 자동 저장됩니다(20초마다, 배달·구매·수집 시점). 모든 접근은 try/catch로 감싸서 저장소를 쓸 수 없어도 게임은 동작합니다.
설정의 시드를 바꾸면 새로운 하늘이 생성되고, 진행도(퀘스트, 깃털, 업그레이드)는 그대로 유지됩니다.
